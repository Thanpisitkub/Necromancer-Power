# Necromancer Origin (Forge 1.20.1 + Origins)

ม็อดเพิ่ม Origin ชื่อ **Necromancer** ให้ Origins (Forge 1.20.1)
- ตัวม็อด (Java) = ระบบสกิล, AI มอนสเตอร์, ระบบมาร์ค, particle
- ตัว Origin/พลัง = ไฟล์ JSON ใน `data/necromancer/` (ผูกปุ่มสกิลให้ผ่าน Apoli)
- Particle ทั้งหมดตัดมาจากชุด `purple_particle_parts_no_beam.zip` ของคุณ (ลบพื้นหลังลายตารางออกให้แล้ว)

## วิธี build
เหมือนโปรเจกต์ก่อนหน้า: อัปโหลด zip นี้ขึ้น GitHub repo แล้วให้ workflow แปลงเป็น jar
(ในโปรเจกต์มี `.github/workflows/build.yml` ใช้ Java 17 + Gradle 8.1.1 + Forge 47.3.0 ให้แล้ว)
ได้ไฟล์ `necromancer-1.0.0.jar` ใส่โฟลเดอร์ `mods` ร่วมกับ Origins (Forge) และ Apoli

## วิธีใช้
1. สร้างโลก/เข้าเซิร์ฟ แล้วเลือก Origin **Necromancer** (ไอคอนหัวกะโหลก Wither)
2. ปุ่มสกิลใช้ปุ่มของ Origins (ดูที่ ตั้งค่า > ปุ่มควบคุม > Origins)
   - `Primary Active` = **Summon**
   - `Secondary Active` = **Dark Magic**
3. **Mark**: คลิกขวาที่ผู้เล่นคนอื่น (มือหลัก) เพื่อมาร์ค/ยกเลิกมาร์ค
   - Monster ที่เสกจะไม่โจมตีคนที่มาร์คไว้
   - คนที่มาร์คจะส่องสว่างสีม่วง **เห็นแค่เรา** (ส่งแพ็กเก็ตหาเราคนเดียว) ในระยะ 50 บล็อก
4. ข้อความสถานะ/คูลดาวน์ขึ้นที่ action bar กลางจอ (ไม่ต้องเปิด log)

## สกิล
**Summon** (คูลดาวน์ 1 นาที นับจากตอนเสก)
- เสก Zombie, Skeleton (ใช้ดาบ ไม่ใช้ธนู), Wither Skeleton — มีทั้งแบบเดินและแบบขี่ม้ากระดูก
- ใส่เกราะเหล็ก + ดาบเหล็กทุกตัว, เลือด 500, วิ่งเร็ว 1.5x, ตีแรง 1.5x, แข็งแกร่ง 1.1x
- ไฟสีม่วงลุกที่หัว, ไม่โจมตีเรา/คนที่มาร์ค/พวกเดียวกัน, ตี Monster ตัวอื่น และ Monster ตัวอื่นก็ตีพวกมัน
- ถ้ายังมีตัวที่เสกอยู่ จะเสกใหม่ไม่ได้จนกว่าจะตายหมด
- ไม่ดรอปของ/XP

**Dark Magic** (คูลดาวน์ 10 วินาที) — ศัตรูในรัศมี 10 บล็อกติด Slowness III, Weakness III, Nausea II นาน 10 วินาที

## ค่าที่ผมตีความเอง (แก้ได้ที่ `config/necromancer-common.toml` หลังรันครั้งแรก)
- จำนวนต่อการเสก: Zombie 2, Skeleton เดิน 1, Skeleton ขี่ม้า 1, Wither เดิน 1, Wither ขี่ม้า 1
- "แข็งแกร่ง 1.1 เท่า" = ค่าเกราะ (armor) x1.1
- "Wither Skeleton โจมตีแล้วไม่มีเอฟเฟค" = ไม่ติดเอฟเฟค Wither
- ประโยค "จะมีตีมอนสเตอร์ที่เราเสกมาด้วยกันเอง" ตีความว่า **ไม่ตีกันเอง**
- Dark Magic = ออกรอบตัวผู้ใช้ (ไม่ใช่ยิงเล็ง) โดนมอนสเตอร์ศัตรูและผู้เล่นที่ไม่ได้มาร์ค
- มอนสเตอร์ที่เสกจะเดินตามและช่วยป้องกันเรา, ถ้าไกลเกิน 48 บล็อกจะวาร์ปมาหา
- มอนสเตอร์จะหายไปเมื่อเราตาย/ออกเกม/เปลี่ยนไปใช้ Origin อื่น
- สีเรืองแสงเปลี่ยนได้ (`glowColor`: `dark_purple` หรือ `light_purple`)

## ข้อควรรู้
- ยังไม่ได้ build/ทดสอบในเกมจริง (เครื่องที่เขียนไม่มี Forge/อินเทอร์เน็ต) ตรวจได้แค่ไวยากรณ์ Java และ JSON
  ถ้า build ไม่ผ่านหรือในเกมมีอะไรผิดปกติ ส่งข้อความ error มาได้เลย
- ไฟล์พลังใช้ชื่อชนิด `apoli:active_self`, `apoli:action_over_time`, `apoli:execute_command`
- คำสั่ง `/necromancer ...` มีไว้ให้พลัง Origins เรียกใช้ (ต้องมีสิทธิ์ OP จึงพิมพ์เองได้)
- คลิกขวาที่ผู้เล่นขณะเป็น Necromancer จะถูกใช้เป็นการมาร์คเสมอ
